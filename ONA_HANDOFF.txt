HOW TO BUILD / CHECK
- No Android SDK/NDK in the cloud container (dl.google.com blocked). Compile check = GitHub CI.
- Every push runs .github/workflows/push_ci.yml -> build.yml (Debug APK, matrix all + arm64, ~9 min).
- Read results with the GitHub MCP tools: actions_list (list_workflow_runs, branch filter),
  actions_get, get_job_logs. The APK is the "debug apk (arm64)" artifact of the run.
- GLSL can be validated locally with glslangValidator (apt install glslang-tools works).
- Java files can be syntax-checked with javac + small stubs (gson jar: /opt/gradle-8.14.3/lib/gson-2.10.jar).
