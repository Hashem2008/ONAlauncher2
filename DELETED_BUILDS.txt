DELETED BUILDS LOG (سجل البنيات المحذوفة)
===========================================
Every time old build files (GitHub Actions artifacts) are deleted to free space, they are written
here first: which repo, which build, which commit and what that commit had. The user asked for this
so any old version can be brought back.

كل مرة بنحذف ملفات بناء قديمة عشان المساحة، بنكتبها هون قبل الحذف: أي مستودع، أي بناء، أي
commit، وشو كان فيه. عشان لو بدك ترجع أي نسخة قديمة.

HOW TO GET ONE BACK (كيف ترجع نسخة)
- The APK file itself cannot be undeleted, but the code of that commit is still in git, so the same
  APK can be built again:
    git push origin <commit>:refs/heads/restore-<commit7>
  Build CI runs on that branch and puts the APK in the release "ona-restore-<commit7>"
  (ONAlauncher2). Or just ask Claude: "رجعلي نسخة <commit7>".
- ملف الـ APK نفسه ما برجع، بس الكود موجود، فبنعيد بناء نفس النسخة من نفس الـ commit.
