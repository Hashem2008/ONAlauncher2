1. Voxy world holes / glitches
   Cause: "Failed to locate library: liblwjgl_zstd.so" - Voxy bundles lwjgl-zstd with PC natives only,
   every LOD section it saved or loaded failed.
   Fix: tools/lwjgl-zstd-android/build.sh (LWJGL 3.3.3 zstd JNI + zstd 1.5.5, NDK clang, arm64) built in
   CI (build.yml, cached, continue-on-error) into jniLibs/arm64-v8a/liblwjgl_zstd.so. Launcher.kt
   addBundledLwjglModules() copies it into the LWJGL natives dir (org.lwjgl.librarypath) before launch.
   Check: launcher log "LWJGL: liblwjgl_zstd.so ready", no zstd error in the game log.
   If the CI step failed: read its log (script prints sources / "Built ... JNI entry points").

2. Shader "Unexpected error while creating framebuffer ... Status: 36054" (Complementary, MobileGlues)
   Real cause: the ONA GL format fix from b669782 NEVER shipped. Only LWJGL/*/src was changed; the merged
   jars in assets/app_runtime/lwjgl/<v>/ were not rebuilt (CI never builds them, local gradle can't reach
   the plugin portal). Now: PojavRendererInit + GLCapabilities compiled with javac (3.3.3: --release 8,
   3.4.1: --release 17) and zipped into lwjgl-<v>-merged-modules.jar, version files changed (device
   re-unpacks). build.yml step "Check LWJGL jars carry the ONA patches" warns if they are stale again.
   ona_glfix.c also: empty allocations (pixels NULL and no unpack buffer) get the format/type pair ES
   accepts for the sized format (Iris allocates RGBA16F / R11F_G11F_B10F with GL_UNSIGNED_BYTE, ES
   rejects that -> empty texture -> 36054). Log lines "[ONA GLFix] glTexImage2D: format ...".
   Check: launcher log "PojavRendererInit: GL format fix on".
   RULE: after changing LWJGL/*/src, rebuild/patch the merged jars the same way.

3. Fabulously Optimized 26.3: nothing on the title screen can be pressed
   Cause: Controlify 3.5 loads SDL "from system" = the game's own libSDL3 (desktop loads its own copy),
   then SDL_SetEventFilter keeps only joystick added/removed events and its tick drains SDL_PollEvent:
   every touch / mouse event is dropped. (Ixeris is NOT it: it disables itself on Android.)
   Fix: sdl_dlopen_hook.c customDlsym: SDL_SetEventFilter / SDL_PollEvent looked up from libjvm/libjava
   (Java FFM = mods; the game's LWJGL binding looks up from liblwjgl) get proxies: filter = no-op,
   poll = SDL_PeepEvents for joystick added/removed only. Controlify stays installed and working.
   Check: launcher log "SDL_Hook: SDL_PollEvent looked up by a mod through Java FFM".

4. DeceasedCraft (Forge 1.20.1): Apocalypse Now, Nameless Trinkets, Create Big Cannons, Legendary
   Survival Overhaul, Immersive Aircraft, FTB Quests, Zombie Extreme, Spore, Farm and Charm missing.
