"Failed to create OpenGL context: Could not bind EGL API".
Cause: SDL_GL_LoadLibrary(path) makes SDL try that path as its EGL first. Minecraft passes LWJGL's GL
library = Kopper's libglxshim, which carries EGL entry points of its own: SDL used that EGL, which
refuses OPENGL_BIT configs and eglBindAPI(EGL_OPENGL_API). ONA's bridge uses libEGL_mesa (POJAVEXEC_EGL),
where binding OpenGL works (Voxyris log: "EGLBridge: Binding to OpenGL", no failure).
Fix: onaSdlGlLoadLibrary (sdl_dlopen_hook.c) still records the GL library for the gl* lookups but, for
"desktopgl" renderers, calls SDL's SDL_GL_LoadLibrary with SDL_EGL_LIBRARY / POJAVEXEC_EGL. GameLauncher:
Kopper Zink's SDL_OPENGL_LIBRARY = the GL library path (was the renderer id "opengles3_desktopgl_zink_kopper").
