1. THE SHADER ERROR (commit 890ea35, ONA Boost 1.2.1)
Log timeline: ONA Boost 1.2.0 active ("keeping 120 FPS ... FLAGSHIP phone"), Complementary
Reimagined r5.9.3 loaded and ran on the POTATO profile (23:37:28), then at 23:38:20
"Profile: COMPLEMENTARY" -> the error. A profile picked in the shader screen switches
WORLD_SPACE_REFLECTIONS / COLORED_LIGHTING back on (bufferObject.0 up to 810 MB, 3D images), after
the launcher's ShaderPackCompat fixed the options file at launch.
Fix inside the game: fabric mixin IrisPackOptionsMixin (@Pseudo, require = 0) = @ModifyArg on the
call ShaderPack.<init>(Path, Map, ImmutableList, boolean) in Iris.loadExternalShaderpack, index 1.
OnaCompat.packOptions(map): when the OpenGL layer has no compute, COLORED_LIGHTING=0,
WORLD_SPACE_REFLECTIONS=-1, WORLD_SPACE_PLAYER_REF=-1 are put into the map Iris loads the pack
with, every time, whatever profile was picked (options a pack does not have are ignored by Iris).
Log line when it had to switch something off: "shader pack: ... kept off (needs compute ...)".
Version 1.2.1 in fabric/gradle.properties, forge/gradle.properties, OnaBoostInstaller.VERSION.
Forge 1.20.1 build has no mixin (Oculus): there only the launch-time fix applies.
Not device-tested: the mixin target was checked with javap against Iris 1.11.7+mc26.3.

3. CONTROLS (commit 82949ba)
- LayerController/utils/ButtonLook.kt: ButtonSkin (CLASSIC, LEGO, PIXEL, GLASS, NEON, BUBBLE),
  PressAnimation (NONE, SHRINK, BOUNCE, SINK), object ButtonLook (Compose state). Read in
